booktracker3000

A single-user Goodreads replacement that stores your books directly in a private GitHub repository. No server, no database — just a JSON file and a personal access token.

Setup
  1. Create (or reuse) a private GitHub repo to hold your book data.
  2. Go to github.com/settings/personal-access-tokens/new and create a Fine-Grained token scoped only to that repository.
  3. Under Repository permissions, set Contents to Read and write.
  4. Copy the token and paste it below, along with the repo owner and name.
